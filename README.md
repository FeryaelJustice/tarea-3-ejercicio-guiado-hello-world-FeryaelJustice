# tarea3-peps
Para la entrega de la tarea 3 de PePS.

Pasos seguidos:
1. ![](steps/paso1.jpg) 

Iniciamos el proyecto en local

2. ![](steps/paso2.jpg) 

Creamos un repositorio en GitHub.

3. ![](steps/paso3.jpg) 

Creamos el repositorio, completamos los datos y creamos el README.

4. ![](steps/paso4.jpg) 

Añadimos el repositorio remoto de GitHub a nuestro repositorio local.

5. ![](steps/paso5.jpg) 

Hacemos git pull del repositorio de GitHub.

6. ![](steps/paso6.jpg) 

Creamos una nueva rama en local y cambiamos a ella.

7. ![](steps/paso7.jpg) 

Hacemos un git commit en la nueva rama.

8. ![](steps/paso8.jpg) 

Hacemos push de nuestro repositorio al repositorio remoto.

9. ![](steps/paso9.jpg) 

Comprobamos que hay nuevos cambios en GitHub y creamos una pull request para que la persona administradora los apruebe y podamos unirlos a la rama main.

10. ![](steps/paso10.jpg) 

Creamos el pull request.

11. ![](steps/paso11.jpg) 

Aceptamos la pull request.

12. ![](steps/paso12.jpg) 

Fusionamos los cambios con la rama principal.

13. ![](steps/paso13.jpg) 

Hemos completado la fusión.
